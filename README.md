# Simple Archiver

Простой файловый архиватор на Go с использованием RLE-подобного алгоритма сжатия и консольного интерфейса на Bubble Tea.

Проект создан в учебных целях для практики работы с:

* Go;
* файловым вводом/выводом;
* буферизированным чтением и записью;
* алгоритмами сжатия;
* обработкой ошибок;
* консольными интерфейсами;
* Bubble Tea.

## Возможности

* Сжатие файлов в формат `.sarch`;
* Распаковка `.sarch`-архивов;
* RLE-подобное сжатие последовательностей одинаковых байт;
* Сохранение исходного имени файла внутри архива;
* Консольное меню;
* Навигация стрелками или клавишами `j` / `k`;
* Обработка ошибок при работе с файлами.

## Требования

* Go 1.21 или новее

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/USERNAME/simple-archiver.git
cd simple-archiver
```

Установить зависимости:

```bash
go mod download
```

## Запуск

Запустить приложение:

```bash
go run .
```

Или собрать бинарный файл:

```bash
go build
```

## Использование

После запуска появится главное меню:

```text
Простой архиватор

> Сжать файл
  Распаковать файл
  Выход

↑/↓ — навигация • Enter — выбрать • q — выход
```

### Сжатие

Выберите `Сжать файл`, затем укажите путь к исходному файлу:

```text
Введите путь к файлу для сжатия:
C:\files\example.txt_
```

После успешного выполнения рядом с исходным файлом будет создан архив:

```text
example.txt
example.txt.sarch
```

### Распаковка

Выберите `Распаковать файл` и укажите путь к `.sarch`-архиву:

```text
Введите путь к файлу для распаковки:
C:\files\example.txt.sarch_
```

Исходное имя файла восстанавливается из информации, сохранённой в архиве.

## Формат архива

Архив содержит:

1. длину имени исходного файла;
2. имя исходного файла;
3. последовательность сжатых блоков.

Для каждого блока хранится его размер и данные.

При RLE-подобном сжатии последовательности из 4 и более одинаковых байт сохраняются в компактном виде:

```text
AAAAAA
```

преобразуется в блок, содержащий длину последовательности и повторяющийся байт.

Более короткие последовательности сохраняются как несжатые данные.

## Структура проекта

На текущем этапе основная логика проекта находится в `main.go`:

```text
simple-archiver/
├── main.go
├── go.mod
├── go.sum
├── README.md
└── .gitignore
```

`main.go` содержит:

* алгоритм сжатия и распаковки;
* работу с файлами;
* форматирование архивных блоков;
* модель Bubble Tea;
* обработку пользовательского ввода;
* консольный интерфейс.
